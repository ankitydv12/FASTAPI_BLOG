FastApi is backend framework , it is used to build backend logic

Features:
   *  Automatic api Documentation
   *  Build in Validation

Create a Obj of the fastapi
    app =FastAPI()
  "The app obj is used in router with decorator , Example: @app.get() , @app.put() "

How to run fast api :
    fastapi dev filename.py -> this for development , automatic reload the server when the changes are  made
    fastapi run filename.py -> this for production

return the list  of dict:
    fast api automatically convert list of dict to array of json

returning the  html response :
    from fastapi.responses import HTMLResponses
